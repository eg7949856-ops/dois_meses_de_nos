# Dois Meses de Nós — versão corrigida

Esta versão incorpora as fotografias diretamente no `index.html`, para evitar erros de caminho no GitHub Pages.

## Publicar no GitHub Pages
1. Baixe e extraia o ZIP.
2. No repositório GitHub que já publica o site, abra a aba **Code**.
3. Apague/substitua o `index.html` antigo pelo `index.html` deste pacote.
4. Faça o commit das alterações.
5. Aguarde alguns minutos e atualize o site com `Ctrl + F5` no computador ou recarregue no celular.

**Importante:** como as fotos ficam dentro do HTML, não é necessário enviar uma pasta `fotos`. Não altere o conteúdo do HTML ao copiar.
